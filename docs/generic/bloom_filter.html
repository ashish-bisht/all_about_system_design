Probabilistic Data Structure

Bloom
Filter

Ek probabilistic data structure jo log ko instantly batata hai — “pakka nahi hai” ya “shayad hai”. False negatives kabhi nahi. False positives kabhi kabhi, wo bhi tunable.

◦ interactive demo
◦ how it works
🔢
HASH

Element ko multiple hash functions se pass karo → bit array positions milti hain.

🟢
SET

Un positions pe bit 0→1. Actual element store nahi hota, sirf bits.

🔍
CHECK

Teeno bits 1? "Shayad hai". Koi 0? "Pakka nahi" → DB hit skip karo.

◦ guarantees
✅
NO FALSE NEGATIVE

Agar element add hua hai to Bloom filter kabhi "nahi hai" nahi kahega.

⚠️
FALSE POSITIVE

"Shayad hai" bol sakta hai jab actual mein nahi hota. Ye probability aap tune kar sakte ho.

🗑️
NO DELETE

Bits shared hoti hain, isliye deletion directly possible nahi. Counting Bloom filters alag topic hai.

◦ real world use cases
🗄️
CASSANDRA / ROCKSDB

Disk read expensive hai. Bloom filter batata hai "pakka nahi" to disk seek skip.

🌐
CHROME SAFE BROWSING

Malicious URLs local Bloom filter se check, "shayad" ayega to network call karte hain.

⚡
CACHE PENETRATION

Redis + DB ke saamne Bloom filter rakho, fake keys DB tak reach hi nahi karte.
