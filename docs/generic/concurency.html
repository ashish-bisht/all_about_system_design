The Real Villain

GIL — Global Interpreter Lock

Python ka ek unbreakable rule hai — ek time pe sirf ek thread Python bytecode execute kar sakta hai. Ye rule enforce karta hai GIL — ek lock jo interpreter ke paas hota hai.

Matlab CPU-bound threading ka koi fayda nahi. Ek thread calculate kar raha hai, doosra simply wait karta rahega chahe 100 cores ho CPU mein.

Toh threading ka koi use nahi? Use hai — I/O operations ke time GIL release ho jaati hai. Jab thread network request bhejta hai ya file read karta hai, wo voluntarily GIL release karta hai. Tab doosra thread kaam kar sakta hai.

💡 Isliye: asyncio > threading for I/O, kyunki asyncio mein ya cooperative hai — tum control karo switch kab ho. Threading mein OS random time pe switch karta hai, GIL contention hoti hai, race conditions possible hain.

Concrete Analogy

Waiter 🍽️ aur Restaurant

Dumb Waiter SYNC / BLOCKING
Table A ka order liya → kitchen mein gaya → khana aane ka wait kiya → serve kiya → ab Table B ke paas gaya → uska order liya → phir wait kiya → serve kiya.

Table B poori time wait karta raha bina kisi wajah ke.
⏱ Total time = Table A ka time + Table B ka time
Smart Waiter ASYNCIO
Table A ka order liya → kitchen mein bheja → wait karne ki bajaye Table B ke paas gaya → uska order liya → kitchen mein bheja → Table A ka khana ready? → serve kiya → Table B ready? → serve kiya.

Ek hi waiter, dono tables khush.
⚡ Total time = max(Table A, Table B)
Key Insight
Cooperative vs Preemptive
asyncio — Cooperative
Sab coroutines "cooperate" karte hain. Har ek explicitly bolta hai await — "main ruk raha hoon, doosra chal." Switch point predictable hai.
threading — Preemptive
OS force karta hai switch — beech mein kisi bhi instruction pe rok sakta hai. Thread ko pata bhi nahi chalta kab ruka. Isliye shared state dangerous hai.

asyncio Gotcha
Ek bhi time.sleep() ya requests.get() async function mein dalega toh poora event loop block ho jayega — matlab koi bhi coroutine nahi chalega jab tak ye khatam na ho.

Hamesha await asyncio.sleep() aur aiohttp use karo.
2026 mein Direction
Pura Python ecosystem async ki taraf shift ho raha hai. FastAPI, SQLAlchemy async, asyncpg, aiohttp — sab async-first hain. Threading manually karna increasingly rare hota ja raha hai. Agar nayi project hai — asyncio se shuru karo.
