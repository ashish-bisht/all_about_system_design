📋 System Design Cheatsheet

⏱️ Latency Numbers Every Programmer Should Know

L1 cache reference .................. 0.5 ns
Branch mispredict .................... 5 ns
L2 cache reference ................... 7 ns
Mutex lock/unlock ................... 25 ns
Main memory reference .............. 100 ns
SSD random read ................. 16,000 ns  (16 μs)
Read 1 MB sequentially (SSD) .. 200,000 ns  (200 μs)
Round trip within datacenter ... 500,000 ns  (500 μs)
Read 1 MB sequentially (disk) 1,000,000 ns  (1 ms)
Disk seek ................... 10,000,000 ns  (10 ms)
Send packet CA→NL→CA ...... 150,000,000 ns  (150 ms)
